# 문제 화면 비주얼 개선 설계 (삐약수학 + 삐약영어 공통)

사용자 피드백: "답 선택 말풍선이 너무 크다, 문제에 집중되게. 초등·중등엔 캐릭터·애니메이션을
많이. 수학이 계산기 같다. 수식이 그냥 텍스트다 (lim·log·Σ 같은 진짜 기호로). 전체 UI 는
나쁘지 않은데 풀 때 실감나는 연출이 있으면 좋겠다."

## 확정 결정

- 외부 라이브러리(Lottie 등) 없음 — 오프라인·의존성 0 원칙 유지. 전부 Canvas + 속성 애니메이션
- 캐릭터는 **병아리 상주 리액션** (문제마다 다른 동물 친구 안은 기각)
- 정답 파티클·콤보, 문제 전환 애니메이션 포함
- **수학 앱 먼저 전부 구현·검증 → 영어 앱에 이식** (수식 렌더는 수학만)
- 두 저장소에 각각 구현 (분리 체제의 공용 코드 복제 방침)

## A. 문제 우선 화면 배분 (두 앱)

- BubbleChoiceView 답판 고정 높이 280dp → **170dp** (2×2 유지, 버블 반지름 축소, 글자 크기 유지)
- 선다 버튼 목록 높이 76→60dp, 숫자 키패드도 축소
- 문제 글자 크기 상향, 답 영역이 준 만큼 문제·그림 영역 확대
- 조작판(시계·저울·바구니·그래프 등)은 문제 그 자체 — 크기 유지

## B. FormulaView — 진짜 수식 렌더 (수학 앱)

Canvas 커스텀 뷰. **팩 텍스트를 그대로 파싱** (재생성 없음 — 생성기가 만든 규칙적 패턴):

| 저장 텍스트 | 렌더 |
|---|---|
| `lim(n→∞) (3n+5)/(4n+2)` | lim 밑에 작은 n→∞, 분수는 가로줄 세로쓰기 |
| `log_3 27` | log 아래첨자 3 |
| `5^2`, `x²` | 위첨자 |
| `√144` | 근호 + 윗줄(vinculum) |
| `(a)/(b)`, `a/b` | 세로 분수 |
| `∫₀^3 3x^2 dx` | 적분 기호 위·아래에 상한 3, 하한 0 (고2 정적분 120문제) |

- 수식 패턴이 감지된 prompt 만 FormulaView, 일반 문장은 기존 TextView
- 파서는 실패 시 **항상 일반 텍스트로 폴백** (크래시 금지)
- 생성기의 계수 1 흉함(`1x²`) 수정 후 팩 재생성 (id 순서는 시드 고정이라 불변)

## C. 병아리 상주 리액션 (두 앱)

문제 화면 상단에 작은 병아리(~52dp) 상주:

- 평소: 숨쉬기(스케일 1.0↔1.04 반복)
- 정답: 점프 + 하트 팡
- 오답: 축 처짐 → 1초 내 회복 (기죽지 않게)
- 15초 무응답: "힘내! 🐥" 말풍선
- **게이트**: 수학 h1~h3, 영어 toeic·toefl 트랙에서는 숨김. 그 외 전부 표시

## D. 정답 파티클 + 콤보 (두 앱, 전 학년)

- 정답 순간 색종이 소량 (TraceView 색종이 물리 재사용, 전체 화면 오버레이)
- 2연속부터 "🔥 N연속!" 배지 팝, 5연속 이상 색종이 증가
- 오답 시 콤보 조용히 리셋 (오답 강조 없음)

## E. 문제 전환 애니메이션 (두 앱, 전 학년)

현재 문제 왼쪽 슬라이드아웃 + 다음 문제 오른쪽 슬라이드인, 약 180ms.
빠른 연속 풀이를 방해하지 않는 길이.

## 검증

- FormulaView 파서 단위테스트: 고등·중등 팩 **전체 prompt 전수 통과**(예외 0),
  lim/log/√/^ 검출 수 하한, 폴백 동작
- 레이아웃 상수 관계 테스트 (버블판 높이 ≤ 문제 영역 최소 확보)
- 실기기 스크린샷으로 배치 확인 (계산으로 못 잡는 겹침 대비)
- 기존 테스트 전부 유지 통과 (수학 61건, 영어 74건)

## 하지 않는 것

- Lottie·GIF·이미지 파일 (원칙 위배)
- 동물 친구 캐릭터 로테이션 (기각됨)
- Σ 렌더 — 현 콘텐츠에 없음 (∫ 는 있어서 포함). 콘텐츠가 생기면 파서에 추가
